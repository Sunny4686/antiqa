# Utkast: begäran om skriftligt tillstånd från Blocket

Till: Blockets kundtjänst/juridik (hitta adress via blocket.se/om eller hjälpcentret; be att få det vidarebefordrat
till den som beslutar om dataåtkomst/API).

**Ämne:** Förfrågan om tillstånd för automatiserad läsning av möbelannonser (internt, låg takt)

Hej,

Jag köper och säljer begagnade skandinaviska designmöbler och har byggt ett internt verktyg som hjälper mig att
snabbt hitta intressanta möbelannonser. Era användarvillkor och robots.txt kräver skriftligt tillstånd för
automatiserad åtkomst, så jag frågar innan jag gör något.

Det jag vill göra:
- Läsa första sidan av kategorin Möbler, sorterad på nyast, högst en gång per 2–5 minuter, samt öppna enskilda
  nya annonser. En förfrågan i taget, med en öppen User-Agent som identifierar mig.
- Endast för internt bruk (1–3 personer). Ingenting publiceras eller säljs vidare, och inga bilder visas
  offentligt.
- Inga personuppgifter sparas (inga säljarnamn, telefonnummer eller profil-id).
- Vid minsta signal om belastning eller blockering stoppar verktyget automatiskt.

Om ni har ett partner-API eller ett flöde (till exempel via Vend/Finn) använder jag hellre det. Ett
tillstånd med andra villkor eller en lägre takt går också bra.
